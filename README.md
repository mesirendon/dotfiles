# My pesonal dotfiles

This project is aimed to boost the installation of software I used on a daily basis. It's tailored for my personal needs. I could accept PRs as long as they do not interfere with my personal configurations and needs.

## Installation
```bash
# Debian/Ubuntu
sudo apt install git -y

# All systems
# clone the repo
git clone git@github.com:mesirendon/dotfiles.git


# enter the repo
cd dotfiles

# run the bootstrap
# some passwords might be prompted
./bootstrap.sh

# restart
sudo reboot
```
